1. Mathematical Statements

A mathematical statement is a declarative sentence that is either true or false, but not both. We name statements with lowercase letters p, q, r, s….

StatementsHave a truth value1 + 1 = 2 (T) · 2 + 3 = 6 (F) · All roses are red (F) · The Philippines has more than 7,100 islands (T) · 7 is an odd number (T) · “For all numbers x, x + 3 = 0” (F)
Not statementsNo definite truth valueQuestions, commands, exclamations (Happy Birthday! · Message me.) · expressions like 5 + 1 · open sentences like x + 3 = 0 · opinions or vague claims (Math is interesting · 7 is a lucky number)

In p → q, p is the premise (hypothesis) and q is the conclusion. The biconditional means (p → q) ∧ (q → p). All connectives are binary except negation, which works on one statement.

Number of rows: n statements give 2n rows (2 letters → 4, 3 letters → 8). Work from the innermost brackets outward.

Implication and equivalence

  • Implication p ⇒ q: p materially implies q (“If it is a cat, then it is a mammal”). A conditional that is always true.
  • Equivalence p ⇔ q: the two can replace each other (“A polygon is a triangle iff it has three sides”). Two statements are equivalent when their truth table columns match in every row.

2. Negation

Simple statements

StatementCorrect negationCommon mistake
1 + 1 = 21 + 1 ≠ 2
All roses are red.Not all roses are red. (= Some roses are not red.)✗ All roses are not red. ✗ All roses are pink.
more than 7,000at most 7,000✗ less than 7,000
at least 18less than 18✗ at most 18
x + y ≤ zx + y > z✗ x + y ≥ z

Why “more than” flips to “at most”: for two numbers, exactly one of <, =, > holds. Ruling out one leaves the other two together.

Compound statements (De Morgan's laws)

~(p ∧ q) ⇔ ~p ∨ ~q flip ∧ to ∨, negate both ~(p ∨ q) ⇔ ~p ∧ ~q flip ∨ to ∧, negate both ~(p → q) ⇔ p ∧ ~q “p happened, but q didn't”

“Jose Rizal is intelligent and nationalistic” → “Jose Rizal is not intelligent or he is not nationalistic.”

3. The Conditional

“If p then q” has many equivalent forms. Using If it is a bird, then it flies:

FormExample
q if pIt flies if it is a bird.
p only if qIt is a bird only if it flies.
p is sufficient for qBeing a bird is sufficient for flying.
q is necessary for pFlying is necessary for being a bird.
All p are q (universal)All birds fly.
Either not p or q (~p ∨ q)Either it is not a bird or it flies.

Tip: “only if” points to the conclusion. “p only if q” is p → q, not q → p.

Converse, inverse, contrapositive

NameFormBird exampleSame as p → q?
Conditionalp → qIf it's a bird, it flies.—
Converseq → pIf it flies, it's a bird.No
Inverse~p → ~qIf it's not a bird, it doesn't fly.No
Contrapositive~q → ~pIf it doesn't fly, it's not a bird.Yes

A conditional is equivalent to its contrapositive. The converse and inverse are equivalent to each other (they're contrapositives of each other), but not to the original.

The module's definition list has a typo, writing the contrapositive as ~p → ~q. The truth table and remark just before it show the correct form, ~q → ~p.

4. Valid and Invalid Arguments

An argument has premises p₁, …, pₙ and a conclusion q. It is valid if, assuming all the premises are true, the conclusion must be true. Validity is about the form, not whether the premises are actually true. A valid argument with true premises is called sound. (Lewis Carroll, author of Alice in Wonderland, wrote logic puzzles to train this.)

Euler diagrams

  • All A are B: circle A inside circle B.
  • Some A are B: overlapping circles.
  • No A is B: separate circles.
  • To show invalid, draw one diagram that fits every premise but breaks the conclusion. If two different diagrams fit the premises but give different conclusions, the argument is invalid.

All dogs are hairy. Cotton is a dog. ∴ Cotton is hairy. Valid: x is in the dogs circle, which is inside the hairy circle.
All dogs are hairy. Cotton is hairy. ∴ Cotton is a dog. Invalid: x can be in the hairy circle but outside the dogs circle.

Valid forms (always tautologies)

Modus ponensp → q, p ∴ qAll dogs are hairy. Cotton is a dog. ∴ Cotton is hairy.
Modus tollensp → q, ~q ∴ ~pAll dogs are hairy. Donut is not hairy. ∴ Donut is not a dog.
Syllogismp → q, q → r ∴ p → rCats are mammals. Mammals are animals. ∴ Cats are animals.

Invalid forms

Fallacy of the conversep → q, q ∴ pAll UP students are diligent. Maria is diligent. ∴ Maria is a UP student. ✗
Fallacy of the inversep → q, ~p ∴ ~qIf you can add, you can subtract. You can't add. ∴ You can't subtract. ✗

To test any of these, load it in the truth table builder above. A valid form gives all T's in the final column (a tautology). The fallacies each have one F row.

Module check (second Example 4.6): its answer key says argument 1 is both a converse and an inverse fallacy. Argument 1 (can't add → can't subtract) is the inverse, and argument 2 (Maria is diligent → UP student) is the converse.

5. Inductive and Deductive Reasoning

DeductiveGeneral → specificAll men are mortal. Socrates is a man. ∴ Socrates is mortal. (Modus ponens, modus tollens and syllogism are all deductive.)
InductiveSpecific → general2, 12 and 22 are even, so all numbers ending in 2 are even. The conclusion can be false, so it still needs a deductive proof.

Induction can fail: 2²−1 = 3, 2³−1 = 7, 2⁵−1 = 31 are all prime, but 2¹¹−1 = 2047 = 23 × 89 is not. Primes of the form 2p−1 are Mersenne primes (after Marin Mersenne).

Pattern problems: the Fibonacci sequence 1, 1, 2, 3, 5, 8, 13 (each term is the sum of the two before). For the triangle puzzle (1–6, each side = 12), put 4, 5, 6 on the corners.
