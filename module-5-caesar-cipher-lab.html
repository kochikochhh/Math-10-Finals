1. What is a Caesar cipher?

A Caesar cipher (or shift cipher) hides a message by shifting every letter a fixed number of places down the alphabet. The number of places is the key, k. According to the Roman historian Suetonius, Julius Caesar used k = 3 for his private letters.

Top row: plain letter. Bottom row: what it becomes with k = 3. A → D, B → E, … and at the end it wraps around: X → A, Y → B, Z → C.

2. The math: modular arithmetic

First, turn letters into numbers. Module 5 numbers them A = 1, B = 2, …, Y = 25, and Z = 0:

Shifting forward means adding k. To make Z wrap back to A, we use mod 26: divide by 26 and keep only the remainder.

Encrypt: C = (P + k) mod 26 Decrypt: P = (C − k) mod 26

Why is Z = 0? Z would be 26, and 26 mod 26 = 0. Some books start at A = 0 instead. For a Caesar shift you get the same ciphertext either way; only the numbers in the working change.

Why it works: it's like a clock. On a 12-hour clock, 9 o'clock plus 5 hours is 2 o'clock, because 14 mod 12 = 2. The alphabet is a clock with 26 positions. This is the same idea as the 4-step cycle table (lamp and tile) in Module 3, which is addition mod 4.

The wrap-around cases

  • Going past Z: Y with k = 3: 25 + 3 = 28, and 28 mod 26 = 2 → B. (Z itself is 0, so Z + 3 = 3 → C.)
  • Going below 0 (decrypting): C with k = 5: 3 − 5 = −2. Add 26 to get back in range: −2 + 26 = 24 → X.
  • Big keys: k = 29 does the same as k = 3, since 29 mod 26 = 3. Only keys 1 to 25 are different, and k = 0 or 26 changes nothing.
  • Decrypting is encrypting backwards: shifting back by k is the same as shifting forward by 26 − k. To undo k = 3, shift forward by 23.
ROT13 (k = 13) is its own inverse: 13 + 13 = 26 ≡ 0 (mod 26), so applying it twice gives back the original. Websites used it to hide spoilers.

3. Cracking the cipher

The Caesar cipher is easy to break, for two reasons.

Brute force: try every key

There are only 25 possible keys. Try them all, and the one that gives readable words is the answer. That takes minutes by hand and an instant by computer.

Frequency analysis

In English, some letters appear far more often than others. E is the most common, followed by T, A, O, I and N. A shift moves every letter by the same amount, so the most common ciphertext letter is probably E in disguise. If the most common ciphertext letter is H, then k = H − E = 8 − 5 = 3. The Arab scholar al-Kindi described this method in the 9th century.

Frequency analysis works best on longer messages. A short message might not have many E's.

Cheat sheet

  • Module 5 numbering: A = 1, B = 2, …, Y = 25, Z = 0. Landmarks: E = 5, J = 10, O = 15, T = 20, Y = 25.
  • Encrypt: C = (P + k) mod 26. Decrypt: P = (C − k) mod 26.
  • If you get 26 or more, subtract 26. If you get a negative number, add 26.
  • Spaces, digits and punctuation stay the same. Only letters shift.
  • Only 25 useful keys, so it's weak. It's broken by brute force or frequency analysis.
  • Find the key from one known pair: k = (cipher letter − plain letter) mod 26.
