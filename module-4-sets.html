1.1 Sets

A set is a well-defined collection of objects: for any object, you can tell whether it is in the set or not. Its members are elements. Write x ∈ A (x is in A) or x ∉ A (x is not in A).

Roster / enumerationV = {a, e, i, o, u}List the elements. E = {2, 4, 6, 8, …}

Not a set{x | x is a large number}Membership isn't clear. 100 is large to some people but not to others. Same with {x | x is beautiful}.
  • Order and repeats don't matter: {a, e, i, o, u} = {u, o, i, e, a}.
  • Finite (you can list all elements) vs. infinite.
  • Cardinality n(A) is the number of elements. n(V) = 5.
  • Empty (null) set: { } or ∅, with no elements.
  • Universal set U: all elements in the discussion, drawn as a rectangle in a Venn diagram.

Module check: page 3 of the module swaps the words: it writes union with “and” and intersection with “or.” That's a typo. Union = or, intersection = and. The module's own worked answers (A ∪ B = {2, 3, 4, 6, 8, 9}, A ∩ B = {6}) use the correct meanings.

Properties

  • Commutative: A ∪ B = B ∪ A, A ∩ B = B ∩ A
  • Associative: (A ∪ B) ∪ C = A ∪ (B ∪ C), and the same for ∩
  • Set difference is not commutative or associative: A \ B ≠ B \ A. Neither is the Cartesian product: A × B ≠ B × A.

Cardinality formulas

n(A ∪ B) = n(A) + n(B) − n(A ∩ B) n(Aᶜ) = n(U) − n(A) n(A \ B) = n(A) − n(A ∩ B) n(A × B) = n(A) · n(B)

Why subtract n(A ∩ B)? Elements in both sets get counted twice when you add n(A) + n(B).

1.3 Relations on Sets

RelationMeaning
Equal A = BExactly the same elements.
Subset A ⊆ BEvery element of A is in B.
Proper subset A ⊂ BA ⊆ B, and B has at least one element not in A.
Equivalent A ∼ BSame number of elements: n(A) = n(B).
DisjointNo common elements.

Equal sets are always equivalent, but equivalent sets need not be equal: {a, e, i, o, u} ∼ {1, 2, 3, 4, 5}.

= and ∼ are reflexive, symmetric and transitive. (⊆ is reflexive and transitive but not symmetric; ⊂ is transitive only.)

Example: L = vowels in “abstemious” = {a, e, i, o, u} = V. M = letters in “abstemious,” so V ⊂ M.

2. Cardinalities of Infinite Sets

2.1 One-to-one correspondence

A and B are in 1-1 correspondence if every element of A pairs with exactly one element of B, and every element of B pairs with exactly one element of A (a bijection). Then A ∼ B. The pairing doesn't have to be unique.

2.2 Countable infinity: ℵ₀

n(ℕ) = ℵ₀ (aleph-null), where ℕ = {1, 2, 3, …}.

SetPairing with ℕCardinality
Even E = {2, 4, 6, …}k ↔ 2kℵ₀
Odd O = {1, 3, 5, …}k ↔ 2k − 1ℵ₀
Counting C = {0, 1, 2, …}k ↔ k − 1ℵ₀
Integers ℤ1, 2, 3, 4, 5… ↔ 0, 1, −1, 2, −2…ℵ₀
Rationals ℚZig-zag diagonally through the k/m tableℵ₀
Definition 2.2: a set is infinite if it is equivalent to a proper subset of itself. (E is a proper subset of ℕ, yet E ∼ ℕ.) This can't happen with finite sets.

Aleph arithmetic: ℵ₀ + 1 = ℵ₀ · ℵ₀ + k = ℵ₀ · ℵ₀ + ℵ₀ = ℵ₀ · ℵ₀ × ℵ₀ = ℵ₀

A set is countable if it is finite or has cardinality ℵ₀. ℵ₀ is the smallest infinite cardinality. ℕ, C, ℤ and ℚ are all countably infinite.

2.3 The real numbers are uncountable

Georg Cantor (1845–1918), founder of set theory, proved that (0, 1) is uncountable using the diagonal argument, a proof by contradiction:

  1. Suppose every number in (0, 1) could be listed: n₁, n₂, n₃, …
  2. Build r = 0.x₁x₂x₃… where each xₖ differs from the k-th digit of nₖ (the diagonal).
  3. Then r differs from every nₖ in at least one digit, so r isn't on the list. That contradicts step 1.
r₁ = 0.12345 r₂ = 0.23456 change the diagonal 1,3,5,7,9 r₃ = 0.34567 → r = 0.25784 is not on the list r₄ = 0.45678 r₅ = 0.56789
  • Any two intervals have the same number of points. (0, 1) ∼ (−1, 1) using f(x) = 2x − 1.
  • An interval ∼ all of ℝ using tan x and arctan x. So ℝ is uncountable and equivalent to its proper subset (0, 1).

Hilbert's Infinite Hotel

David Hilbert's thought experiment: a fully booked hotel with infinitely many rooms can still take a new guest (everyone moves from room n to n + 1), and even infinitely many new guests (move to room 2n, which frees the odd rooms). It works for any countable crowd, but not for one guest per real number.
